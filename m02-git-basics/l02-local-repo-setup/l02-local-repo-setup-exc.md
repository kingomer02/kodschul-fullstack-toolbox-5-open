# Lab 2.2 - Übung: Lokales Repo für das Kursprojekt anlegen

**Dauer:** ca. 25 Minuten
**Ändert die TeamBoard-Projektbasis?** Ja - legt das TeamBoard-Repo an.

## Vorbereitung

- `output/project/starter/README-draft.md` (aus Modul 1) liegt lokal vor, oder du erstellst ihn neu.

## Aufgaben

1. Erstelle einen Ordner `teamboard/` und initialisiere ihn mit `git init`.
2. Lege eine `.gitignore` mit `node_modules/`, `dist/` und `.env` an.
3. Lege `index.html` mit einem minimalen HTML-Grundgerüst an (Titel: "TeamBoard").
4. Kopiere deinen `README-draft.md` aus Modul 1 in den Ordner.
5. Committe `.gitignore`, `index.html` und `README-draft.md` in einem Commit mit aussagekräftiger Nachricht.

## Checkpoint

- `git status` zeigt einen sauberen Zustand (keine offenen Änderungen).
- `git log --oneline` zeigt genau einen Commit.

## Abschlusskriterien

- `teamboard/` ist ein gültiges Git-Repo mit den drei genannten Dateien im ersten Commit.

## Fallback

Falls kein eigener README-Entwurf aus Modul 1 vorliegt: einen einfachen Platzhaltertext verwenden und in Modul 7 spätestens präzisieren.
