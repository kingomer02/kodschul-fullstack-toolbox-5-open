# TeamBoard (starter)

TeamBoard is a minimal Kanban ticket system built across this course.

## Ticket

- `title: string`
- `description: string`
- `assignee: string`
- `status: "To Do" | "In Progress" | "Done"`

## Actions

- create a ticket
- assign a ticket to a person
- change a ticket's status (move it between columns)

This file is the starting point generated in Module 1 with Copilot Chat. It intentionally contains no implementation yet - that is built module by module starting on Day 2.
