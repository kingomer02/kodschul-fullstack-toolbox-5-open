# Lab 5.1 - Übung: Grundlagen und Installation

**Dauer:** ca. 15 Minuten
**Ändert die TeamBoard-Projektbasis?** Nein - reine Verifikation, keine Projektdatei betroffen.

## Ausgangslage

Node.js LTS ist gemäß Vorbereitungshinweisen installiert.

## Aufgaben

1. Prüfe mit `node --version` und `npm --version`, dass beide funktionieren.
2. Schreibe ein Skript `hello.js`, das deinen Namen und `process.version` ausgibt.
3. Führe das Skript mit `node hello.js` aus.
4. Ändere das Skript so, dass es zusätzlich `process.platform` ausgibt, und führe es erneut aus.

## Checkpoint

- `node hello.js` gibt Name, Node-Version und Plattform ohne Fehler aus.

## Abschlusskriterien

- Beide Befehle (`node --version`, `npm --version`) liefern eine Versionsnummer, keine Fehlermeldung.

## Fallback

Bei fehlender/fehlerhafter Installation: Trainer-Laptop oder Cloud-IDE (z. B. bereitgestelltes Codespace) als Ausweichumgebung nutzen.
