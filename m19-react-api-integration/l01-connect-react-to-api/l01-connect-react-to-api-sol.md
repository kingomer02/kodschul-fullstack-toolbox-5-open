Siehe vollständigen Code im Theorieteil (Lab 19.1, Abschnitt "Minimalbeispiel: Daten laden").

## Aufgabe 4: Netzwerk-Tab prüfen

Beim Laden der Seite erscheint in den Entwicklertools eine Anfrage an `https://jsonplaceholder.typicode.com/users` mit Status `200` und einer JSON-Antwort mit mehreren Nutzerobjekten.

## Grenzen

Diese API erlaubt kein Schreiben echter, dauerhafter Daten (Änderungen werden simuliert, aber nicht wirklich gespeichert) - ausschließlich zum Üben von Leseoperationen geeignet.
