# Lab 17.1 - Übung: Schneller HTML schreiben mit Emmet

**Dauer:** ca. 20 Minuten
**Ändert die TeamBoard-Projektbasis?** Nein - eigenständige Übungsdatei.

## Vorbereitung

- Eine leere Datei `sample-html/emmet-practice.html` mit einem minimalen `<html><body></body></html>`-Grundgerüst liegt bereit.

## Aufgaben

1. Erzeuge per Emmet-Kürzel (`Tab` in VS Code) ein `<div class="column" id="todo">` mit einer `<h2>To Do</h2>` und zwei `div.ticket>p{Ticket-Titel}`-Kindelementen.
2. Erzeuge per Emmet ein zweites `div.column#in-progress` nach demselben Muster, aber mit nur einem Ticket.
3. Erzeuge per Emmet eine `<ul>` mit fünf `<li>`-Einträgen für eine Beispiel-Navigation.
4. Vergleiche die Zeit, die du für Aufgabe 1-3 per Emmet gebraucht hast, mit einer Schätzung, wie lange dasselbe HTML per Hand getippt gedauert hätte.

## Checkpoint

- Alle drei HTML-Strukturen sind vollständig und korrekt verschachtelt vorhanden, ohne dass ein schließendes Tag von Hand getippt wurde.

## Abschlusskriterien

- Du kannst mindestens zwei verschiedene Emmet-Operatoren (`>`, `+`, `*`, `.`, `#`) korrekt in eigenen Worten erklären.

## Fallback

Falls Emmet in VS Code nicht reagiert: Kommandopalette → "Emmet: Expand Abbreviation" manuell auslösen, statt auf Tab zu warten.
